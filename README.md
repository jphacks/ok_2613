# カッスニア

「オトナのあそび」には、代償がつきもの。

カッスニアは、夜の街を舞台に、競馬・スロット・喫煙所を巡るブラウザゲームです。レトロなRPG風の導入から、それぞれ異なるミニゲームや会話体験へ進めます。

## 製品概要

### 背景・開発のねらい

「次こそ当たる」「もう少しだけ」――大人の娯楽には、つい続けたくなる魅力があります。

その雰囲気や、お金を使う選択、人との何気ないやり取りを、架空の街で体験できる作品を目指しています。

しかし、このようなゲームは社会的にどうなんだと疑問を持たれる方も多いことと思います。

ですが、有名な例としてGTAシリーズの発売直後に犯罪率が低下する、という研究結果が出ています。

これは「潜在的に犯罪を行う可能性のある人」がゲームという娯楽に時間を費やすことで犯罪の「機会」そのものが減少するからだと言われています。

私たちは、仮想場で「オトナのあそび」を体験する機会を提供することで、抑圧された未成年と、今まさに「オトナのあそび」に依存している成人に対して

一定の抑止力として機能することを一つの狙いとして今回の開発へと至りました。

### 製品説明

迷子になった主人公がたどり着いたのは、不思議な夜の街「カッスニア」。怪しい人物の「セイジンビーム」で20歳になった主人公は、街に並ぶ施設へ足を踏み入れます。

プレイヤーは名前を入力し、物語を経て街へ移動します。街から好きな施設を選び、それぞれの体験を楽しめます。

### 特長

#### 1. RPG風の街から始まる体験

ドット風フォント、文字送り、画面の切り替え演出で、街に迷い込む導入を表現しています。プレイヤー情報を保存し、続きから再開できます。

#### 2. 展開が読めないミニゲーム

- **競馬場「カオス競馬 DX」**：個性の異なる5頭から馬を選び、架空のコインを賭けてレースを観戦。転倒・居眠り・覚醒などのイベントが順位を左右します。距離の変更や音声実況にも対応しています。
- **カジノ「ROYAL FRUIT SLOTS」**：ベット額を選んで3列のリールを回し、停止ボタンで結果を確認。絵柄が揃うと配当やボーナス演出が発生します。

#### 3. 訪れるたびに変わる喫煙所の物語

**喫煙所「一服のあいだ。」**では、夜の喫煙所で架空の人物と短い会話を交わします。返答の選択と、火をつけて長押しし、離す操作を組み合わせた演出が特徴です。訪問を重ねると会話や関係が変化し、置き手紙などの展開へつながります。

### この作品で体験できること

- 実際のお金を使わずに、予想・ベット・結果発表の流れを遊ぶこと。
- 同じ街の中で、にぎやかなゲームと静かな会話の両方を楽しむこと。
- 自分の選択や再訪によって、人物との関係が変わる物語を読むこと。

### 今後の展望

- 街に表示されている「居酒屋」の実装。
- 施設をまたぐ共通の所持金や、行動の結果を振り返る仕組み。
- 各施設の体験をつなぐストーリーやイベントの追加。
- 連続で施設を利用した後に発生する慈善活動イベントの追加（教育・抑止目的）

上記は構想です。現時点で居酒屋は「準備中」と表示され、各ゲームのコインは共通化されていません。

### 注力したこと

- 街を入口に、異なる雰囲気の体験へ移動できる構成。
- 馬ごとの性格とランダムイベントを組み合わせたレース展開。
- 喫煙所での会話、煙の視覚演出、環境音を組み合わせた空気感。
- ブラウザ内への進行状況の保存。

## 遊び方・起動方法

Python 3が利用できる環境で、リポジトリのルートから次のコマンドを実行します。

```sh
python3 -m http.server 8000
```

ブラウザで [http://localhost:8000](http://localhost:8000) を開いてください。依存パッケージのインストールやビルドは不要です。

1. タイトル画面からゲームを開始し、名前を入力します。
2. 導入の物語を進めて、街へ移動します。
3. 行きたい施設を選び、画面内の案内に沿って遊びます。
4. 各施設の戻るボタンで街へ戻れます。

喫煙所はJavaScriptのES Modulesを利用するため、HTMLファイルの直接表示ではなく、HTTPサーバー経由で起動してください。

## 開発技術

### 活用した技術

| 技術 | 用途 |
| --- | --- |
| HTML / CSS / JavaScript | 画面、演出、ゲームロジック |
| ES Modules | 喫煙所の機能分割 |
| localStorage | プレイヤー情報、競馬のコイン、喫煙所の物語進行の保存 |
| Web Audio API | 効果音・環境音 |
| Web Speech API | 競馬の音声実況 |
| Google Fonts | 街の画面などのフォント |

フロントエンドフレームワークやバックエンドサーバーは使用していません。音声実況の利用可否や声はブラウザ・端末によって異なります。Google Fontsの取得にはインターネット接続が必要です。

### 主な実装

- [街・導入ストーリー](index.html)：シーン遷移、文字送り、施設の選択、プレイヤー情報の保存。
- [競馬](games/horse-racing/index.html)：馬の特性、ランダムイベント、順位と配当の計算。
- [スロット](games/slot/index.html)：リール制御、当たり判定、ボーナス演出。
- [喫煙所](games/cigarette/smoking-room.js)：会話と喫煙演出を連動させる進行制御。
- [共通の戻るボタン](back-button.js)：各施設から街への移動。

### ディレクトリ構成

```text

│   ├── slot/                 # スロット

├── js/                       # 計算用関数など

└── LICENSE
```


## データの保存について

進行状況は利用中のブラウザのlocalStorageに保存されます。ブラウザや端末を変えての引き継ぎはできません。サイトデータを削除すると保存内容も消えます。
